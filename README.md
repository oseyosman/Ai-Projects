# 10 AI & Machine Learning Projects

A structured, hands-on learning roadmap for mastering foundational Machine Learning and Data Science concepts, implemented step by step in Python.

---

## 📌 Projects Roadmap

| # | Project | Problem Type | Dataset | Primary Tools | Status |
|---|---------|--------------|---------|---------------|:------:|
| **01** | [Michigan House Price Prediction](./01_house_price_prediction) | Regression | Michigan Housing Real Estate Dataset | Python, Scikit-learn, Pandas |
| **02** | [Email Spam Detection](./02_email_spam_detection) | Binary NLP Classification | Enron / SMS Spam Collection | Python, Scikit-learn |
| **03** | [Handwritten Digit Recognition](./03_handwritten_digit_recognition) | Multi-class Image Classification | Sklearn Digits (MNIST-like) | Python, Scikit-learn |
| **04** | [Iris Flower Classification](./04_iris_flower_classification) | Multi-class Classification | UCI Iris Dataset | Python, Scikit-learn |
| **05** | [Movie Recommendation System](./05_movie_recommendation_system) | Collaborative Filtering | MovieLens | Python, Scikit-learn, SciPy |
| **06** | [Customer Segmentation](./06_customer_segmentation) | Unsupervised Clustering | Mall Customers | Python, Scikit-learn (K-Means) |
| **07** | [Sentiment Analysis](./07_sentiment_analysis) | NLP Text Classification | Amazon Reviews | Python, Scikit-learn (TF-IDF) |
| **08** | [Image Classification](./08_image_classification) | Deep Learning (CNN) | CIFAR-10 | Python, PyTorch |
| **09** | [Titanic Survival Prediction](./09_titanic_survival_prediction) | Tabular Classification | Kaggle Titanic | Python, Scikit-learn |
| **10** | [Stock Price Prediction](./10_stock_price_prediction) | Time Series Forecasting | Yahoo Finance | Python, Pandas, Scikit-learn, yfinance |

## 🛠️ Environment & Prerequisites

- **Python**: 3.10+
- **Key Libraries**: `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `joblib`, `torch`, `torchvision`, `yfinance`

To install or verify common dependencies:
```bash
pip install numpy pandas scikit-learn matplotlib seaborn joblib torch torchvision yfinance
```
